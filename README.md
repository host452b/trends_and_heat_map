### 口碑方差解读

- **0-1.5 (绿)** = 评价稳定，该职业体验可预期
- **1.5-2.5 (黄)** = 多数认可，少数不同看法
- **2.5-5 (红)** = 两极分化，体验取决于雇主/城市/个人

### 色阶规则

评分列 (0-10): `ratio = max(0, min(1, (score - 3) / 7))` → 红→黄→绿，`rgba(r,g,b, 0.35)`

口碑方差 (0-5): 反向色阶，0=绿色(稳定) → 5=红色(分化)

### 口碑方差解读

- **0-1.5 (绿)** = 评价稳定，该职业在该国体验可预期
- **1.5-2.5 (黄)** = 多数认可，少数不同看法
- **2.5-5 (红)** = 两极分化，体验取决于雇主/城市/个人
